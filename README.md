# Razgovor.uz — bepul dars (VSL, 20 daqiqa)

Слайды бесплатного урока-VSL: 14 минут урока («3 шаблона → 48 фраз») + 6 минут презентации курса.
Холст 1920×1080, масштабируется под любой экран.

**Онлайн:** https://damir1703.github.io/razgovor-dars/

## Управление

| Клавиша | Действие |
|---|---|
| → / пробел, ← | вперёд / назад (сначала шаги внутри слайда) |
| L | язык UZ / RU |
| T | полный текст сценария (`?text=1`): можно скопировать или сохранить в PDF |
| N | заметки спикеру с таймингом |
| H | режим записи: без кнопок (`?rec=1`) |
| S | пошаговое появление вкл/выкл (`?steps=0`) |
| P | раскладка: весь экран или 60/40, слева спикер (`?split=1`) |
| F | полный экран |

## Где что лежит

- `src/data.ts` — все цифры и факты: тарифы, цены, состав курса, глаголы и шаблоны урока, данные опроса.
- `src/slides/a.tsx` — часть 1, проблема · `b.tsx` — часть 2, урок · `c.tsx` — часть 3, курс.
- `src/slides/index.ts` — порядок слайдов, шаги и подсказки спикеру.
- `src/script.ts` — полный текст спикера по слайдам (UZ и RU).
